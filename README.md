# BL Unlock Sender

Android-приложение (Kotlin), которое подаёт заявку на разблокировку загрузчика
в **глобальном** Xiaomi Community точно в момент сброса квоты:
**00:00 по Пекину = 19:00 по Москве**.

## Как получить APK
GitHub → вкладка **Actions** → последний запуск **Build APK** → артефакт
`BlUnlockSender-apk` (zip, внутри `app-release.apk`).

## Как пользоваться
1. **Войти в Mi** — откроется официальная страница входа Xiaomi. После входа
   приложение само заберёт cookie `new_bbs_serviceToken`. Если не сработало —
   «Токен вручную» (значение cookie из браузера с new.c.mi.com/global).
2. **Проверить статус аккаунта** — покажет, можно ли подавать заявку
   (аккаунт должен быть старше 30 дней).
3. За 5–10 минут до 19:00 МСК нажать **Запустить**, держать экран включённым и
   приложение открытым. Время синхронизируется по NTP, задержка до сервера
   замеряется за минуту до сброса и вычитается.
4. После одобрения — Mi Unlock Tool на ПК (обычно с ожиданием 72 ч).

## Параметры
- **Сдвиг** (по умолчанию −100 мс) — когда отправить первую заявку относительно 00:00:00.
- **Попыток** (10) и **интервал** (100 мс) — серия запросов; при одобрении серия прекращается.

Не ставьте слишком много попыток — частые запросы могут привести к временной
блокировке аккаунта для заявок.
